# Liquid Calm — Privacy Policy

The privacy policy for **Liquid Calm**, published by UTrendtek, Inc.

Live at **https://utrendtek.github.io/liquid-calm-privacy/**

## Why this repository exists

Both the App Store and Google Play require a publicly reachable privacy policy
URL before they will accept a submission. GitHub Pages serves one for free.

It is a separate repository from the app on purpose. The app repository is
private and holds signing configuration, release notes and store copy; this one
is public and holds only the policy. There is no path from here to anything
else.

## The policy, in one line

Liquid Calm collects nothing and sends nothing. It has no network permission on
Android, makes no network requests on iOS, and contains no analytics,
advertising, crash reporting, accounts or third-party code.

## Editing it

`index.html` is one self-contained file — no external requests, no trackers, no
web fonts. It reads correctly in light and dark mode.

The source of truth lives with the app, at `legal/site/index.html` in the
`liquid-calm` repository, so the policy stays versioned alongside the software it
describes. Edit it there, change the date at the top, then copy it here.
